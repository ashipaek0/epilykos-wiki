If you already use Home Assistant, the **Home Assistant** source can pull in any of its entities. That
means anything Home Assistant knows about, such as a Shelly energy meter, a smart plug, or another
inverter integration, can show up on your Epilykos dashboard.

To go the other way and show Epilykos metrics in Home Assistant, see
[Epilykos in Home Assistant](/publishing/home-assistant).

## What you need

- Your Home Assistant address, for example `http://192.168.1.50:8123`.
- A **long-lived access token**. In Home Assistant, open your profile, go to **Security**, and under
  **Long-lived access tokens** press **Create token**.

The token is stored encrypted.

## Set it up

<Steps>
<Step>

In **Settings → Sources**, press **+ Add Home Assistant server** and give it a name.

</Step>
<Step>

Enter the address and the access token, then press **Fetch Entities** to load your entity list.

</Step>
<Step>

Press **+ Add Metric Mapping** for each value you want, and pair a metric name (for example
`grid_power`) with an entity (for example `sensor.shelly_em_grid_power`).

</Step>
<Step>

Set the **Poll Interval (s)**; somewhere between 30 and 60 seconds works well. Then **Save changes**.

</Step>
</Steps>

## Which entities you can use

Epilykos lists entities from these domains: `sensor`, `binary_sensor`, `switch`, `light`, `climate`,
`fan`, `cover` and `input_boolean`.

States like `on` and `off` are kept as they are, and the grid status card and the switch cards read
them directly. So a `binary_sensor` that tells you whether the grid is up can be your
[grid status metric](/settings/prices-and-savings#grid-status).

## Controlling Home Assistant

Control cards can call Home Assistant services, for example to switch an entity on or off, and the
slider and knob can set `number` and `input_number` values. These cards live on the
[Controls page](/dashboard/controls).
