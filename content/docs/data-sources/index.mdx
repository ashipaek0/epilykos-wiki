A source is one connection that Epilykos reads from. You add them in **Settings → Sources → Add
source**, or let the [setup wizard](/getting-started/first-run-setup) set up the first ones for you.

## Which source do I need?

| Your equipment | Source | Guide |
| --- | --- | --- |
| An inverter with a Wi-Fi logger stick: Solarman V5, LuxPower, Growatt, Felicity | **WiFi dongle** | [Inverter dongles](/data-sources/inverter-dongles) |
| An inverter with a Bluetooth module: LuxPower, Phocos Any-Grid, SRNE and Renogy-style modules | **WiFi dongle**, with the connection set to Bluetooth | [Inverter dongles](/data-sources/inverter-dongles) |
| An inverter or charge controller with an RS-485 (Modbus) port | **Modbus (RS485 or TCP)** | [Modbus](/data-sources/modbus) |
| A Victron GX device (Cerbo, CCGX, Venus OS) | **Modbus (RS485 or TCP)**, over TCP | [Modbus](/data-sources/modbus) |
| Voltronic, Axpert, Infinisolar, MUST, Sako; Phocos Any-Grid; Victron VE.Direct; SolaX | **RS232 serial** | [RS232 serial](/data-sources/rs232) |
| A battery with a Bluetooth BMS | **Battery management (BMS)** | [Battery BMS](/data-sources/bms) |
| A battery with a wired RS485 / UART BMS port | **Wired BMS** | [Battery BMS](/data-sources/bms) |
| Anything that's already in Home Assistant | **Home Assistant** | [Home Assistant](/data-sources/home-assistant) |
| Devices that publish to an MQTT broker | **MQTT** | [MQTT](/data-sources/mqtt) |
| Tuya or Smart Life plugs, meters and switches | **Tuya** | [Tuya](/data-sources/tuya) |
| Anything with a web API that returns JSON | **REST API** | [REST API](/data-sources/rest-api) |

[Supported hardware](/data-sources/supported-hardware) lists every device profile that comes with
Epilykos.

## Adding a source

<Steps>
<Step>

Go to **Settings → Sources** and press **Add source**. Pick the type and press **Continue**.

![The Add a source dialog, grouped into inverter, home automation and battery sources](/images/sources-add-source.webp)

</Step>
<Step>

Fill in the connection details. For Modbus, RS232 and WiFi dongle sources, also pick the **profile**
that matches your model.

</Step>
<Step>

Choose which readings to keep. Each mapping row is one reading: a metric name on one side, and on the
other the register, entity, topic or field it comes from. Profile-based sources can fill these in for
you with **Load Profile Registers** or **Load Profile Fields**. Keep the suggested names or type your
own; see [naming conventions](/getting-started/core-concepts#naming-conventions).

</Step>
<Step>

Press the source's test button (**Test Connection**, **Test Modbus**, **Test Broker** and so on) to
make sure it reads, then **Save changes** in the bar at the bottom.

</Step>
</Steps>

Most source types can hold more than one device, so you add one card per inverter, dongle or battery
pack.

## Several inverters or batteries

Add each one as its own source, with its own metric names (dongle sources have a **Metric Prefix**
field to make this easy). Then, in **Settings → Metrics → Combined metrics**, you can add their
readings together or work out energy from power. Battery packs can also be combined into a
[battery bank](/data-sources/bms#battery-banks).

## Bluetooth devices

Bluetooth batteries and inverter Bluetooth modules all share the computer's Bluetooth adapter, which
has a few consequences:

- Devices on the same adapter are read one after another. With several of them, allow about 10
  seconds per device in their read intervals, for example 60 seconds for six.
- Most devices only accept one Bluetooth connection at a time, so close the manufacturer's phone app
  while Epilykos is connected.
- On Docker, Bluetooth needs a Linux host and access to the host's D-Bus socket. See
  [Install with Docker](/getting-started/install-docker#bluetooth).
