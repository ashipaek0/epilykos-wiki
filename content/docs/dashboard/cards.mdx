The layout editor's library has every card, grouped as below. Cards that draw energy flows, charts,
tables, costs and savings use your [metric roles](/getting-started/core-concepts#metric-roles), so set
those first.

## Try them in the showcase

`/showcase` shows every card filled with made-up readings from an imaginary home, updating every few
seconds. Try each card's options (size, titles, periods, styles) to see what it can do. Nothing on the
page reads your data or reaches your devices. It needs sign-in.

## Energy flow

| Card | What it shows |
| --- | --- |
| **System topology** | Animated flow between solar, battery, grid and home |
| **System overview** | Grid, battery, solar and home tiles with 24-hour sparklines, around the inverter |
| **Flow card** | Power flow with an optional solar gauge |
| **Flow square** | Square flow layout with your inverter image |
| **Flow square, alternate** | Square flow layout without the inverter image |

These need the power roles, or metrics picked on the card.

![The System topology card with made-up readings](/images/cards-system-topology.webp)

## Values

| Card | What it shows |
| --- | --- |
| **Metric cards** | A row of large single values |
| **Metric trend** | A live metric with an optional history or forecast graph |
| **Dual metric** | Two live values side by side |
| **Multi-value list** | Label, value and unit rows |
| **Text metric** | One metric's current value as text |
| **Grid status** | Grid on/off, hours, a 24-hour timeline, and optional costs and hours per day |
| **Day totals** | Energy to and from the grid, consumption and solar today, against forecast |
| **Savings** | Savings today, this week, month, year and all time |

**Grid status** needs the [grid status metric](/settings/prices-and-savings#grid-status). **Savings**
needs the daily solar role and your [prices](/settings/prices-and-savings).

## Gauges and bars

| Card | What it shows |
| --- | --- |
| **Gauge** | One value on a round dial |
| **Configurable gauge** | A fully configurable dial with bands and history |
| **Half gauge** | One value on a semicircle |
| **Half gauge, centre zero** | Zero at the top; fills right, or left for negative values |
| **Bar gauge** | Horizontal bars for several metrics |
| **Bar gauge, segmented** | LED-style segmented bars for several metrics |
| **History bars** | One metric's history as coloured vertical bars |
| **Stacked history bars** | Several metrics stacked per time bucket |
| **Threshold bar** | One value against coloured bands |

These work with any metric.

## Charts and tables

| Card | What it shows | Needs |
| --- | --- | --- |
| **Power chart** | Solar, load, battery and grid power over time (24 hours or 3 days); a generator series appears when it ran | The power roles |
| **Energy chart** | Daily solar, grid and load energy as bars (7 days by default) | The daily energy roles |
| **Energy day** | Hourly consumption, solar and generator with forecast, and battery charge | The power roles |
| **Energy flows** | Where each hour's energy came from and went | The power roles |
| **Costs and earnings** | Grid and generator costs, grid earnings and battery wear per hour, with day totals | The power roles and your prices |
| **Energy, tabbed** | Energy day, flows, costs and day totals in one card | As above |
| **Metric chart** | Any metrics over time, with units and scale | Any metric |
| **Daily table** | Day-by-day energy totals (30 days) | The daily energy roles |
| **Monthly table** | Month-by-month energy totals (12 months) | The daily energy roles |

![The Energy day card: hourly consumption and solar with forecast, and the battery charge below](/images/cards-energy-day.webp)

## Forecast and weather

| Card | What it shows |
| --- | --- |
| **Solar forecast** | Today's production, the next days, weather and a chart |
| **Solar forecast summary** | Today and the next days, without the chart |
| **Solar forecast chart** | Today's actual against forecast solar power |
| **PV today** | Summary bar, weather timeline and chart |
| **Weather** | Conditions, forecast and alerts |

These need [Forecast and weather](/settings/forecast-and-weather) set up.

![The Solar forecast card: today's production, the next three days and forecast against actual power](/images/cards-solar-forecast.webp)

## Controls

| Card | What it does |
| --- | --- |
| **Toggle switch** | Turns an entity on or off |
| **Button** | Big icon button: tap to toggle, turn on or off, or press |
| **State select** | Picks one of several states for an entity |
| **Slider** | Drag to set a number, such as a charge current or a level |
| **Rotary knob** | Turn a knob to set a number |

Control cards work only on the Controls page; on a dashboard they show a link to it. See
[Device controls](/dashboard/controls).

## Text and embeds

| Card | What it shows |
| --- | --- |
| **Text** | A note or heading you write |
| **Embed** | Another web page in a frame |
