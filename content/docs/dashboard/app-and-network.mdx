Epilykos is a Progressive Web App: you can install it on a phone, tablet or computer and open it like
any other app.

## Install it

Open the dashboard in your browser, then:

- **Android (Chrome):** menu → **Install app** or **Add to Home screen**.
- **iPhone and iPad (Safari):** Share → **Add to Home Screen**.
- **Desktop (Chrome, Edge):** the install icon in the address bar.

On iPhone and iPad, [push notifications](/settings/notifications) only work once Epilykos is added
to the Home Screen.

## What the app does

| Feature | Detail |
| --- | --- |
| Live updates | New readings are pushed to the open dashboard as they arrive. |
| Offline shell | The app's own files are cached, so it opens without a connection. |
| Background refresh | Where the browser supports it (Chrome), the installed app asks to refresh readings about every minute even while closed; the browser decides how often it really runs. |
| Instant start | The last dashboard state is kept on the device, so it shows straight away when reopened. |
| Home and away addresses | The app tries your home address first and falls back to the away address. |

## Home and away addresses

Set these in **Settings → Network**:

- **Address at home**, for example `http://192.168.1.10:3000`. Used when your phone or computer is on
  your home network: fast, and works without internet.
- **Address away from home**, for example `https://energy.example.com`. Used everywhere else.

The app tries the home address first and switches to the away address when it can't reach it. Both
addresses are handed to the app's service worker when you save them, so open Settings and save them
once on each device you install the app on.

Don't have an away address? [Tailscale or a Cloudflare Tunnel](/settings/network-and-remote-access)
gives you one, and Tailscale fills in **Address away from home** for you.

## Troubleshooting

If live updates stop with *closed before connection is established*, an old service worker is in the
way: unregister it (browser settings → site data for the Epilykos address) and reload. Behind a
reverse proxy, also check its [WebSocket settings](/settings/network-and-remote-access#reverse-proxy).
