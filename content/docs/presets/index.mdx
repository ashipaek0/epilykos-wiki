A preset is a finished dashboard saved as a small JSON file. Download it, import it, and you have a
good-looking starting point to adjust, instead of an empty grid.

## Use a preset

**In the app (quickest):** open the [layout editor](/dashboard/editor) (`/editor`, signed in), press
**Import / export → Browse presets…**, pick one and press **Add dashboard**. It is added next to your own
dashboards, and you can undo it right after. The gallery needs Epilykos 1.3.5 or newer.

**From a file:** download the preset's JSON file from its page, then in the editor choose
**Import / export → Import from file…**. Choose **Append** to add it next to your own dashboards.
(**Replace** swaps all of yours for it, so only pick that on a fresh install.)

Either way, open the new dashboard from the dashboard list and adjust it.

A preset only holds layout and style: it never contains your readings, passwords or addresses. Cards that
show a reading use the usual metric names (such as `pv_total_power`), so they fill in once you've set up
the [metric roles](/getting-started/core-concepts#metric-roles). A card whose metric you don't have simply
shows nothing until you point it at one.

## Share your own

Made a dashboard you like? In the editor, open it and choose **Import / export → Export this dashboard**.
That file is all a preset is. If you'd like it listed here, send it with a screenshot through the
[contributing guide](/development/contributing).
