The first time you open Epilykos, head to `/setup`. On EpilykosOS that's
`http://epilykos.local:3000/setup`. On Docker it's `http://localhost:3000/setup` from the same
computer, or something like `http://192.168.1.10:3000/setup` from another device. The wizard sets your
admin password, connects your equipment and builds you a first dashboard. You can change anything it
sets later in Settings.

## The wizard

<Steps>
<Step>

### Password

The admin password protects Settings and the layout editor. The dashboard itself stays open for
anyone to look at.

![The setup wizard's password step](/images/setup-password.webp)

- **If no password is set yet**, whoever opens the wizard first gets to choose it, so open it yourself
  right after the first start.
- **Use at least 12 characters.** The wizard will accept 4, but you won't be able to open Epilykos to
  the internet (with Tailscale's **Open to the internet** or a Cloudflare Tunnel) until the password
  is at least 12 characters long. **Generate a strong password** makes a long one for you.
- **On Docker with `SETTINGS_PASSWORD` set**, the wizard asks you for that password instead. See
  [Install with Docker](/getting-started/install-docker).

</Step>
<Step>

### Sources

Pick what Epilykos should read from, then fill in the details for each one:

| Group | Choices |
| --- | --- |
| Inverter | WiFi or Bluetooth dongle, Modbus-TCP, RS485 (Modbus-RTU), RS232 serial |
| Battery | BMS over Bluetooth (scans for nearby batteries), BMS over RS485 / RS232 |
| Home automation and other | Home Assistant, MQTT, REST API |

![The setup wizard's Sources step, with the seven steps listed on the left](/images/setup-sources.webp)

Testing each connection is optional, and a failed test won't stop you carrying on. Tuya devices are
added later, in Settings. [Data sources](/data-sources) explains each type in detail.

</Step>
<Step>

### Metrics

Tell Epilykos which reading is your solar power, which is your battery level, which is what the house
is using, and so on. These [metric roles](/getting-started/core-concepts#metric-roles) power the flow
card, your savings and the daily totals. If you don't have something, just leave it empty.

</Step>
<Step>

### Dashboard

Choose a layout to start from:

- **Everything** (8 cards): the system overview, today's totals, energy charts, the forecast, the
  grid, your savings and history. You can remove whatever you don't need later.
- **Simple** (3 cards): just the system overview, today's totals and your savings.

</Step>
<Step>

### Basics

- **Site time zone** (EpilykosOS only): daily totals follow it. It's filled in from your browser.
- **Dashboard title**, shown at the top of the dashboard.
- **Currency symbol** for your savings, for example €, $, £ or ₦.
- **Solar array size (kWp)**: the total size of your panels, used for the solar forecast.
- **Grid buy price per kWh**, plus the **generator buy price** if you mapped a generator.
- **Theme** for this browser. Each device remembers its own choice.

</Step>
<Step>

### Extras

These are all optional and can be set up in Settings later: uploads to
[PVOutput](/settings/uploads), the [solar forecast](/settings/forecast-and-weather), and the
[addresses the app uses at home and away](/dashboard/app-and-network).

</Step>
<Step>

### Finish

Look over what you've set up, finish, and open your dashboard.

</Step>
</Steps>

Once setup is done, opening `/setup` again just tells you that *Epilykos is already set up*. Sign in if
you want to run it again.

## The pages you'll use

| Address | What it is | Sign-in |
| --- | --- | --- |
| `/` | The live dashboard | No |
| `/settings` | Settings | Yes |
| `/editor` | The [layout editor](/dashboard/editor) | Yes |
| `/showcase` | Every card filled with made-up readings; see [Cards and the showcase](/dashboard/cards) | Yes |
| `/controls` | [Device controls](/dashboard/controls) | Yes |
| `/setup` | The setup wizard | Yes, once setup is finished |

## If someone else set the password first

If the wizard says Epilykos is already set up but you never chose a password, someone else got there
first. You can take it back:

- **On Docker**, set `SETTINGS_PASSWORD` under `environment:` in the compose file and run
  `docker compose up -d`. That password then unlocks setup and Settings.
- **On EpilykosOS**, reset the password with a file on the SD card; see
  [Password and factory reset](/epilykos-os/password-and-reset).
