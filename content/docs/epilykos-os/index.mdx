EpilykosOS is an operating system made just for running Epilykos on a Raspberry Pi. You write it to a
memory card, power the Pi on, and finish setting up in your browser. After that it behaves like an
appliance: it runs, updates and recovers by itself, without you having to look after it.

To get started, see [Install on a Raspberry Pi](/getting-started/install-epilykos-os).

## Hardware

- A Raspberry Pi 3B. Support for the Pi 4 and Pi 5 is planned.
- A microSD card of 32 GB or more; 64 GB is recommended.
- An Ethernet cable or a 2.4 GHz Wi-Fi network.

## How it compares with Docker

| | EpilykosOS | Docker |
| --- | --- | --- |
| Setting up | Write the card, power on, open `http://epilykos.local:3000` | Install Docker, then set up the compose file |
| Wi-Fi, port and time zone | Changed from Settings | Set on the computer and in the compose file |
| Epilykos updates | Signed releases, installed by the box and rolled back if they don't start properly; can be automatic | `docker compose pull`, or **Update now** with the Docker socket |
| A forgotten password | A file on the SD card | `SETTINGS_PASSWORD` in the compose file |
| Restart, shut down, factory reset | **Settings → System** | Restart only |
| Pairing Bluetooth devices with a PIN | **Settings → System → Bluetooth devices** | Done on the computer itself |
| SSH | **Settings → System**, off to start with | The computer's own |

## Safe updates

- Epilykos updates are kept separate from updates to the operating system, so each can be rolled back
  on its own.
- Every Epilykos release is pinned by its digest, so the box runs exactly the release that was checked
  and nothing else.

There's more in [Updates and recovery](/epilykos-os/updates-and-recovery).

## Release channels

| Channel | What you get |
| --- | --- |
| **Stable** | Reviewed releases, for boxes in everyday use |
| **Dev** | Builds for testing what's coming next |
