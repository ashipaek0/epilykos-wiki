EpilykosOS is a dedicated operating system for running Epilykos on a Raspberry Pi. You flash it,
power it on and finish setup from a browser. From then on it runs, updates and recovers by itself,
like an appliance.

To install it, see [Install on a Raspberry Pi](/getting-started/install-epilykos-os).

## Hardware

- A Raspberry Pi 3B. The Pi 4 and Pi 5 are planned, best effort.
- A microSD card of 32 GB or larger; 64 GB is recommended.
- Ethernet or 2.4 GHz Wi-Fi.

## What's different from Docker

| | EpilykosOS | Docker |
| --- | --- | --- |
| Setup | Flash, power on, open `http://epilykos.local:3000` | Install Docker, write the compose file |
| Wi-Fi, port, time zone | From Settings | From the host and the compose file |
| App updates | Signed releases, installed by the box, rolled back if unhealthy; optionally automatic | `docker compose pull`, or **Update now** with the Docker socket |
| Forgotten password | A file on the SD card | `SETTINGS_PASSWORD` in the compose file |
| Restart, shut down, factory reset | **Settings → System** | Restart only |
| Bluetooth pairing with a PIN | **Settings → System → Bluetooth devices** | On the host |
| SSH | **Settings → System**, off by default | The host's own |

## Safe updates

- Application updates are separate from OS updates and can be rolled back on their own.
- Every application image is pinned by its digest, so the box runs exactly the release that was
  checked.

More in [Updates and recovery](/epilykos-os/updates-and-recovery).
