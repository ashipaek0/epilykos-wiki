Both of these need the box, or its SD card, in your hands, or an SSH login you've set up yourself.
That's deliberate: nobody else can reset your password over the network.

## Forgot the dashboard password?

Pick a new password of 12 to 128 characters, then set it in one of these two ways.

<Tabs items={["SD card", "Keyboard and screen"]}>
<Tab value="SD card">

1. Shut the box down and put its SD card in your computer.
2. On the card's boot drive, create a file called `dashboard-password.txt` with the new password on
   its first line.
3. Put the card back and start the box.

The box deletes the file once it has used it. If it can't use the password, it leaves the file on the
card and keeps the old one.

</Tab>
<Tab value="Keyboard and screen">

On the console, or over SSH if you've switched it on, run:

```bash
sudo epilykos-reset-password
```

</Tab>
</Tabs>

Either way, [two-step sign-in](/settings/security#two-step-sign-in) is switched off as well, so losing
your phone can never lock you out.

## Factory reset

A factory reset erases everything the box keeps: Epilykos's data and settings, backups, Wi-Fi
networks, SSH settings and keys, Bluetooth pairings and logs. The box then restarts as if you'd just
written the card, and you set it up again over Bluetooth or with `wifi.txt`.

<Callout type="warn">
  If you might want your data back, download a backup first: **Settings → Backup and restore →
  Download backup**.
</Callout>

| From | How |
| --- | --- |
| The dashboard | **Settings → System → Factory reset** |
| The SD card | Create a file called `factory-reset.txt` on the boot drive, with the word `ERASE` on a line of its own, and start the box. |
| A keyboard and screen | Run `sudo epilykos-factory-reset` on the console, and type `ERASE` when it asks. |
