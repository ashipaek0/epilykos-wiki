Both need physical access to the box or its SD card.

## Forgot the dashboard password?

<Tabs items={["SD card", "Keyboard and screen"]}>
<Tab value="SD card">

1. Shut the box down and put its SD card in your computer.
2. On the card's boot drive, make a file named `dashboard-password.txt` with the new password on its
   first line (4 to 128 characters).
3. Put the card back and start the box.

The file is deleted once it's used.

</Tab>
<Tab value="Keyboard and screen">

On the console, or over SSH if you've turned it on, run:

```bash
sudo epilykos-reset-password
```

</Tab>
</Tabs>

Either way also switches [two-step sign-in](/settings/security#two-step-sign-in) off, so a lost phone
never locks you out.

## Factory reset

A factory reset erases everything the box keeps: Epilykos data and settings, backups, Wi-Fi networks,
SSH settings and keys, Bluetooth pairings and logs. The box then restarts as if newly flashed, and is
set up again over Bluetooth or `wifi.txt`.

<Callout type="warn">
  Download a backup first if you want your data back later: **Settings → Backup and restore →
  Download backup**.
</Callout>

| From | How |
| --- | --- |
| The dashboard | **Settings → System → Factory reset** |
| The SD card | Put a file named `factory-reset.txt` with the word `ERASE` on a line of its own on the boot drive, and start the box. |
| Keyboard and screen | Run `sudo epilykos-factory-reset` on the console, and type `ERASE` when asked. |
