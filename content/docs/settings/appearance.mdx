**Settings → Appearance** controls how the dashboard looks, and which dashboard opens on computers and
on phones.

## Branding

| Field | What it does |
| --- | --- |
| **Dashboard title** | The title shown at the top of the dashboard. |
| **Logo URL** | A logo image, shown at the top left. |
| **Favicon URL** | The little icon shown on the browser tab. |

## Background and blocks

These settings are the **default look for every dashboard**. Any one dashboard can change them for itself;
see [Dashboard style](/dashboard/editor#dashboard-style) in the layout editor.

| Field | What it does |
| --- | --- |
| **Background in light mode** and **Background in dark mode** | A background colour for each theme. |
| **Background image URL** | A picture behind the dashboard, instead of a plain colour. |
| **Transparent blocks** | Makes the cards see-through, which looks good over a background picture. |
| **Square corners** | Gives the cards square corners instead of rounded ones. |
| **Glass cards** | Blurs and tints what is behind each card, like frosted glass. It replaces Transparent blocks while it is on, and looks best over a background picture. **Glass blur** and **Glass frost** set how strong it is. |

The title, logo and favicon are the same on every dashboard.

## Default dashboards

Choose which dashboard opens **On computers** and which **On phones**. To rename, add, delete, import
or export dashboards, use the [layout editor](/dashboard/editor).

## Light and dark

Choose **Light**, **Dark** or **Auto** at the bottom of the settings menu. Each browser remembers its
own choice.
