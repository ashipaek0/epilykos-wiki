**Settings → Appearance** sets how the dashboard looks and which dashboard opens on each device.

## Branding

| Field | What it does |
| --- | --- |
| **Dashboard title** | Shown at the top of the dashboard. |
| **Logo URL** | A logo image, shown at the top left. |
| **Favicon URL** | The browser tab icon. |

## Background and blocks

| Field | What it does |
| --- | --- |
| **Background in light mode** / **Background in dark mode** | A colour for each theme. |
| **Background image URL** | An image behind the dashboard instead of a colour. |
| **Transparent blocks** | Makes card backgrounds see-through, for a cleaner look over a background image. |
| **Square corners** | Cards without rounded corners. |

## Default dashboards

Pick which dashboard opens **On computers** and which **On phones**. Rename, add, delete, import or
export dashboards in the [layout editor](/dashboard/editor).

## Light and dark

Choose **Light**, **Dark** or **Auto** at the bottom of the settings menu. Each browser remembers its
own choice.
