**Settings → Network** is about how you reach Epilykos, at home and away.

## This box

Shows how the computer running Epilykos is connected. On EpilykosOS it also has **Wi-Fi** (to join a
different network, see [Wi-Fi setup](/epilykos-os/wifi-setup)) and **Dashboard address**, where you
change the port (80, or 1024 to 65535; Epilykos restarts on the new port and the page follows it).

## App addresses

**Address at home** and **Address away from home** tell the installed app where to find Epilykos. See
[Install as an app](/dashboard/app-and-network#home-and-away-addresses).

![The App addresses card](/images/settings-app-addresses.webp)

## Remote access with Tailscale

No reverse proxy or port forwarding needed. Under **Remote access**, press **Connect with Tailscale**.

![The Remote access card before connecting](/images/settings-remote-access.webp)

<Steps>
<Step>

Sign in at the link (or scan the QR code) with your own Tailscale account. Tailscale is free for
personal use.

</Step>
<Step>

Press **Create my address**. You get an HTTPS address such as
`https://epilykos.your-tailnet.ts.net`. Only devices signed in to your Tailscale account can open it:
install the Tailscale app on your phone and sign in with the same account. If your Tailscale network
hasn't turned on HTTPS yet, the card shows a link to do it once.

</Step>
<Step>

It fills in **Address away from home** if that is empty, so the installed app switches to it
automatically.

</Step>
</Steps>

**Open to the internet** (off by default) uses Tailscale Funnel so any browser can open the address.
Anyone with the address can then reach your sign-in page, so it asks for your admin password, which
must be at least 12 characters.

How it runs: the image includes Tailscale's latest stable release at build time. `tailscaled` runs
inside Epilykos in userspace networking mode, started only when you turn remote access on, so no
compose changes or extra permissions are needed. Its state is kept in `data/tailscale/`, not in
database backups.

**Turn off remote access** logs this device out of your Tailscale network. Remote access can only be
turned on by a signed-in admin.

## Remote access with a Cloudflare Tunnel

For a public address on your own domain (the domain must be on Cloudflare), with no ports to open:

<Steps>
<Step>

In Cloudflare Zero Trust, go to **Networks → Tunnels** and create a tunnel of type **Cloudflared**.

</Step>
<Step>

Copy the install command it shows and paste it into **Tunnel token or install command** under
**Cloudflare Tunnel**. Just the token, starting with `eyJ`, works too.

</Step>
<Step>

In Cloudflare, under **Public hostname**, add your address (for example `energy.example.com`) with
service **HTTP** and URL `localhost:3000`. Enter the same address in **Public address** in Epilykos,
and press **Connect tunnel**.

</Step>
</Steps>

Connecting asks for your admin password, which must be at least 12 characters, because the address is
reachable from anywhere. Add Cloudflare Access to the hostname if you want an extra sign-in in front.

`cloudflared` runs inside Epilykos only while the tunnel is on. The token is stored encrypted, passed to
`cloudflared` through its environment rather than its command line, and hidden in the logs and the
diagnostics file. **Turn off tunnel** stops it and forgets the token.

The released image is rebuilt every Monday, so Tailscale, `cloudflared` and the base system's
security fixes arrive even without a new Epilykos release.

## Reverse proxy

Epilykos pushes live updates over a WebSocket at `/ws`. Behind a reverse proxy (Caddy, Nginx,
Traefik, Cloudflare), make sure WebSocket upgrade headers are forwarded.

<Tabs items={["Caddy", "Nginx"]}>
<Tab value="Caddy">

```text title="Caddyfile"
your-domain.com {
    reverse_proxy localhost:3000 {
        header_up Upgrade {http.request.header.Upgrade}
        header_up Connection {http.request.header.Connection}
        flush_interval -1
    }
}
```

</Tab>
<Tab value="Nginx">

```nginx
location / {
    proxy_pass http://localhost:3000;
}

location /ws {
    proxy_pass http://localhost:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
```

</Tab>
</Tabs>

**Cloudflare proxy (orange cloud):** WebSockets work on all plans. Make sure the record is proxied,
not DNS-only, and that no firewall rule blocks WebSocket traffic.

The installed app's service worker deliberately doesn't touch `/ws`: WebSocket connections go
straight to the browser's own WebSocket support.
